# For Mom — A Birthday Experience

A responsive, single-page birthday experience made with plain HTML, CSS, and JavaScript.

## Preview

After GitHub Pages is enabled, the site will be available at:

https://irhsrykhan01.github.io/test/

## Enable GitHub Pages

1. Open the repository **Settings**.
2. Select **Pages** from the left sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose branch **main** and folder **/(root)**, then save.
5. Wait for GitHub Pages to publish the site. The URL will appear on the Pages settings screen.

## Features

- Cinematic welcome screen and responsive editorial-style layout.
- A locally generated ambient melody, with an option to choose an audio file from the device.
- Photo gallery with a full-screen lightbox.
- Local photo uploads for the current browser session. Photos selected in the browser are not uploaded to GitHub or any server.
- Two mini-games: Petal Garden and Find the Love.
- Random birthday wishes, confetti, and a personal letter section.
- No framework, build step, API key, account, or paid service required.

## Personalize it

- Edit the birthday message and letter in index.html.
- Update the colors and layout in assets/style.css.
- Adjust game behavior, wishes, and music in assets/app.js.
- To make personal photos permanent on the website, add the image files to the repository (for example, in assets/photos/) and change the image paths in index.html. The browser-only photo upload button is intended for temporary previews on the device.

## Run locally

Open index.html in a modern browser, or use any static file server. No installation is needed.
